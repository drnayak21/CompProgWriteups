# A. Subset Selecting

**Problem:** Given an array of `n` integers and an integer `k`, divide some elements into disjoint groups, each containing at least `k` elements. Maximize the mex of the groups' maximum elements.

## Input
- `t`: Number of test cases.
- `n, k`: Array length and minimum group size.
- `a1, a2, ..., an`: Array elements.

## Output
For each test case, print the maximum possible mex of the group maximums.

**Constraints:** `1 ≤ t ≤ 500`, `1 ≤ k ≤ n ≤ 100`, `0 ≤ ai ≤ n`.
