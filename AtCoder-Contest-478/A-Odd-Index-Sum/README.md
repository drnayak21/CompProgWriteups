# A - Odd Index Sum

## Problem Statement

You are given a sequence of `N` integers. Find the sum of the elements at odd positions (1st, 3rd, 5th, and so on).

## Input

The first line contains an integer `N`, representing the number of elements.

The second line contains `N` integers representing the sequence.

## Output

Print the sum of the elements at odd positions.

## Sample Input 1

```text
5
3 1 4 1 5
```

## Sample Output 1

```text
12
```

## Explanation

The elements at odd positions are `3`, `4`, and `5`.

Their sum is `3 + 4 + 5 = 12`.

## Sample Input 2

```text
6
2 7 1 8 2 8
```

## Sample Output 2

```text
5
```

## Explanation

The elements at odd positions are `2`, `1`, and `2`.

Their sum is `2 + 1 + 2 = 5`.
