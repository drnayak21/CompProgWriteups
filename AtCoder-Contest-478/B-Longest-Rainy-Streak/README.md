# B - Longest Rainy Streak

## Problem Statement

Takahashi recorded the weather for `N` days. `S` represents a sunny day and `R` represents a rainy day. Find the maximum number of consecutive rainy days. If there are no rainy days, print `0`.

## Input

The first line contains an integer `N`, the number of days.

The second line contains a string `S` of length `N`, consisting of `S` and `R`.

## Output

Print the maximum number of consecutive rainy days.

## Sample Input 1

```text
7
RRSRRRS
```

## Sample Output 1

```text
3
```

## Sample Input 2

```text
10
SSSSSSSSSS
```

## Sample Output 2

```text
0
```

## Sample Input 3

```text
20
RRRSRRRRSSRRRRSRSRRR
```

## Sample Output 3

```text
4
```
