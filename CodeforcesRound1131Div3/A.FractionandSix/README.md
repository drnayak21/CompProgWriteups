# A. Fraction and Six

## Problem
Given two strings p and q, representing the numerator and denominator of a fraction, determine whether we can cancel common characters and rearrange the remaining numerator to form "six", with nothing remaining in the denominator.

## Input
- First line contains t, the number of test cases.
- Each test case contains two integers n and m.
- The next line contains string p (numerator).
- The following line contains string q (denominator).

## Output
Print "YES" if the simplified fraction can form "six", otherwise print "NO".

## Example

### Input
5
4 1
sinx
n
6 7
xixsms
mixsxim
8 5
fixtures
frute
3 3
abc
def
5 10
sixty
codeforces

### Output
YES
NO
YES
NO
NO
