# A. Perfect Sandwiches

## Problem Statement
Given `a` slices of cheese and `b` slices of sausage, find the maximum number of sandwiches possible.

Each sandwich must contain at least one slice of cheese and sausage, with strictly more cheese than sausage. All slices must be used.

If it is impossible, print `-1`.

## Input
The first line contains an integer `t`, the number of test cases.

Each test case contains two integers `a` and `b`, representing the number of cheese and sausage slices.

## Output
For each test case, print the maximum number of sandwiches possible, or `-1` if it is impossible.

## Example

**Input**
```text
3
6 4
5 1
4 5
```

**Output**
```text
2
1
-1
```
